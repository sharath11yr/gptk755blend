# Analog Electronics series - approved style (owner approved the RC high-pass demo, Nov 2026)

- The viewer knows NOTHING. Baby steps. Explain in depth; length is fine.
- Circuit on the LEFT, live waveforms on the RIGHT, drawn in step.
- Show current as moving charges, every half-cycle; component states (charges on plates, etc.).
- Every number on screen computed from the circuit. No mistakes - verify every value.
- NO boxes, NO flowcharts, NO "diagram" scenes. Direct content only.
- Structure: build the circuit piece by piece -> compare with what they know -> key idea ->
  each half-cycle / operating case -> special point (e.g. cutoff) -> worked formula -> common mistakes -> recap.
- Check every rendered video frame by frame before upload.
- Every topic gets its OWN circuit and its OWN animation built for it (no reusing one scene with
  new labels). The circuit, waveforms and what moves all change with the topic.
- Thumbnails: the owner uploads them himself - never auto-generate.
- Shorts may run up to 90 seconds: use the time to explain the main concept properly (hook -> idea shown -> payoff).
